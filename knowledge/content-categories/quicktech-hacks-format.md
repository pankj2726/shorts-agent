# QuickTech Hacks Content Formats, Banned Topics & Viral Angles [VERIFIED]

## 1. The Four Pillar Formats
Every QuickTech Hacks Short must strictly belong to one of four approved pillar formats:

1. **Shortcut Secrets (Format ID: `P1-SHORTCUT`):**
   - Focus: Windows, Mac, Browser, or OS navigation shortcuts saving >=10 minutes daily.
   - Pacing: Problem demonstration (0-5s) -> Shortcut execution (5-18s) -> Pro tip modifier (18-28s).
2. **Hidden Utility Spotlight (Format ID: `P2-UTILITY`):**
   - Focus: Built-in operating system features 90% of users don't know exist (e.g., Windows Sandbox, Mac Quick Look).
   - Rule: Never recommend unvetted third-party `.exe` or paid software.
3. **Workflow Automation & AI Hacks (Format ID: `P3-AUTOMATION`):**
   - Focus: 100% free AI tools or browser extensions automating tedious manual tasks.
   - Requirement: Verify free tier is active and requires no credit card.
4. **Excel & Data Wizardry (Format ID: `P4-DATA`):**
   - Focus: Dynamic arrays, `XLOOKUP`, flash fill, clean visualization tricks in modern spreadsheet tools.

## 2. Banned & Policy-Risk Topics (Zero Tolerance)
Any script touching these topics triggers immediate rejection at QA Stage A:
- **Piracy & Software Cracking:** "How to get software for free", torrenting, bypass activation keys.
- **Hacking & Unauthorized Access:** Wi-Fi cracking, password bypass, surveillance tools.
- **Financial Get-Rich-Quick:** Crypto trading bots, speculative investing, affiliate spam.
- **Medical / Health Advice:** Ergonomic or medical claims without recognized certification.
- **Policy-Risk Disclaimers:** Phrasing such as "guaranteed to work", "they don't want you to know".

## 3. High-Retention Framing Angles
- **The Contrarian Angle:** "Stop doing [common action] — do this instead."
- **The Cheat Code Angle:** "This feels illegal to know, but it's completely built into Windows."
- **The Lazy Person's Angle:** "If you have 100 files to rename, never do it one by one."
